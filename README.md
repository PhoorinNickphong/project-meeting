# แอปจดประชุม

แอปเดสก์ท็อปสำหรับจดประชุมภาษาไทยบน Windows วางแผนให้บันทึกเสียง ระบุผู้พูดด้วยปุ่มลัด และถอดเสียงบนเครื่องด้วย Rust และ Whisper

## สถานะโครงการ

กำลังพัฒนาเฟส 1 มีแกน Rust สำหรับผูกการเปลี่ยนผู้พูดกับเวลาเสียงแล้ว รุ่นทดลองแรกจะเน้นการอัดเสียง การระบุผู้พูด และการเปิดฟังย้อนหลัง

- [บอร์ดติดตามงาน](project-tracker.html) เปิดไฟล์ในเบราว์เซอร์ของเครื่องเพื่อย้ายการ์ดและบันทึกสถานะ
- [หน้าตัวอย่างแอป](preview/meeting-notes.html) แสดงตำแหน่งปุ่มผู้พูดและข้อความถอดเสียงด้วยข้อมูลจำลอง
- [ภาพบอร์ดติดตามงาน](preview/project-board.png)
- [บอร์ด GitHub Projects เฟส 1](https://github.com/users/PhoorinNickphong/projects/1)
- [GitHub Milestone เฟส 1](https://github.com/PhoorinNickphong/project-meeting/milestone/1)
